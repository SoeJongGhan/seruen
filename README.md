# Seruen AI — помощник по прогулкам в Астане

RAG-система, которая подсказывает, куда сходить прямо сейчас: с учётом того, где вы, сколько у вас
времени, что сейчас работает и что вы любите. Кейс НИЦ Smart City, хакатон Build with AI.

> «Я возле Mega Silk Way, хочу прогуляться 30–60 минут» → 1–3 конкретных места с реальным маршрутом
> и временем в пути, объяснением «почему» и планом «что там делать». Каждое место — из базы 2ГИС
> со ссылкой, идеи модели помечены отдельно.

**Что умеет**

- Рекомендации по свободному запросу — текстом или голосом, на русском, казахском и английском.
- Учитывает время и часы работы, бюджет времени, способ передвижения, сезон и **погоду**
  (в мороз и ветер — места в помещении).
- **Реальные маршруты 2ГИС**: пешком, на машине и на общественном транспорте — с номерами
  автобусов и линией на карте 2ГИС; кнопка «Открыть маршрут в 2ГИС».
- **3D-пролёт** (three.js): настоящая карта 2ГИС в перспективе, светящийся маршрут по реальным улицам,
  лучи света над точками, камера облетает каждую остановку с карточкой места; день, вечер и ночь —
  по выбранному времени. Работает для подборки и для квеста.
- **Пульс города** (three.js): все 1 634 места каталога столбиками над картой 2ГИС. Высота —
  популярность × оживлённость в выбранный час (оценка по типу места, дню недели и почасовому прогнозу
  Open-Meteo: в мороз и дождь парки «пустеют», ТРЦ и кафе — наоборот). Ползунок времени и «Прожить
  день», индекс оживлённости, «Где сейчас жизнь» (топ районов, подлёт камеры), слои «♥ Советуют
  в ленте» и «Предложения заведений», маркер «Вы здесь».
- **«Как на фото»**: загрузите любую картинку с атмосферой (например, из Pinterest) — модель
  с поддержкой изображений описывает её и превращает в запрос, Seruen подбирает похожие по типу
  и особенностям места из каталога.
- **Фото-отметка в квесте** (+30 очков, значок «Фотоохотник»): модель проверяет снимок вслепую — ей
  не говорят, какое место ждут; она определяет место среди точки квеста и соседних объектов, и отметка
  засчитывается, только если выбрана нужная точка. Без этого модель соглашалась с подсказкой.
- **Seruen для бизнеса**: кафе и развлекательные центры подключают своё заведение из каталога (заявку
  проверяет команда — `ADMIN_EMAILS` в `.env`), публикуют скидки, события и новинки с днями и часами
  действия, видят показы и переходы. Интеграция с кассой или CRM — REST API по ключу (`X-Api-Key`,
  в базе хранится только хеш). **Предложения не влияют на подбор и порядок мест**: они показываются
  только в карточке заведения, которое и так подошло человеку, с пометкой «Реклама».
- **«Что это за место?» по фото**: модель с поддержкой изображений (`GROQ_VISION_MODEL`) выбирает место
  из заметных объектов рядом, сверяясь с описаниями 2ГИС; если ошиблась — «Не то? Может быть: …».
  Дальше — «Что рядом» или «Квест отсюда». Фото не сохраняется.
- **Воронка подбора** над ответом: сколько мест отсеял каждый шаг (база → тип → радиус → открыто →
  лучшие → выбрано) и время этапов — настоящие числа с сервера.
- **Мини-маршрут** из 3 мест в порядке обхода, режим **компании** (2–8 человек), доступная среда,
  «с ребёнком», «с ноутбуком».
- «Где я» — геолокация браузера; «Показать другие» — ещё три места без нового поиска;
  «Прочитать вслух».
- **Квест-прогулка**: 2–3 интересные точки рядом, реальный пеший маршрут 2ГИС, на каждой точке —
  задание и вопрос о месте. Вопросы составлены только по описаниям из 2ГИС, правильный ответ
  перемешивается и проверяется кодом. Отметка «Я на месте» — по геолокации (радиус 200 м).
- **Паспорт города**: очки за отметки, ответы и квесты, уровни («Гость столицы» → «Знаток Астаны»),
  штампы по категориям мест и значки («Ночной город», «Морж» — отметка в мороз ниже −15°).
  Хранится только в браузере пользователя.
- **Аккаунты**: регистрация и вход по email (Supabase Auth), профиль с отзывами, лайками и паспортом;
  паспорт хранится в аккаунте и доступен с любого устройства, очки гостя при входе переходят в аккаунт.
  Навигация — навбар сверху, на телефоне — нижняя панель.
- **Лента** (отдельная страница): люди делятся местами из каталога с коротким отзывом и ставят лайки; сортировка
  «Новое / Популярное / Рядом», посты на карте. Места, которые советуют люди, мягко поднимаются в
  рекомендациях («♥ советуют в ленте»). Отзывы проходят модерацию (`gpt-oss-safeguard-20b`) и фильтр
  телефонов, почты и ссылок; три жалобы скрывают пост.
- **Панель администратора** (раздел «Админка», виден только админу): сводка, заявки заведений
  (одобрить/отклонить), модерация ленты (жалобы, скрыть/вернуть/удалить), выключение предложений,
  пользователи, состояние системы. Админ — роль в Supabase `app_metadata`, её ставит только сервер:
  `python -m seruen.make_admin email@... [--password ...]` (снять — `--revoke`).
- Прозрачность: ссылка «Почему эти места?» — как поняли запрос, где и с какими фильтрами искали,
  все рассмотренные места, откуда данные.

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows; на macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env              # заполнить ключи (см. ниже)

python -m seruen.collect          # собрать базу мест из 2ГИС -> data/pois.json (уже собрана)
python server.py                  # приложение на http://localhost:8000
python -m seruen.demo_seed        # демо-наполнение ленты (удалить: --remove)
python -m seruen.scenarios        # прогнать тестовые сценарии -> data/scenario_results.json
```

Нужные ключи в `.env`:

| Переменная | Зачем |
|---|---|
| `DGIS_API_KEY` | сбор мест (Places API), маршруты (Routing и Public Transport API) |
| `GROQ_API_KEY` | LLM (`openai/gpt-oss-120b`, разбор запроса — `gpt-oss-20b`) и распознавание речи (Whisper) |
| `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` | озвучка ответа (необязательно) |
| `SUPABASE_URL`, `SUPABASE_KEY`, `SUPABASE_SERVICE_KEY` | лента и аккаунты: публичный ключ — для входа, серверный (service_role) — для базы и регистрации. В SQL Editor выполнить `db/schema.sql`, `db/002_auth.sql`, `db/003_business.sql` |
| `GROQ_VISION_MODEL` | распознавание фото: «Что это за место?», «Как на фото», фото-отметка |
| `ADMIN_EMAILS` | email-адреса команды через запятую — кто одобряет заявки заведений |

## Как это работает

```
запрос ──► 1. Разбор (LLM) ──► 2. Поиск по базе (код) ──► 3. Ответ (LLM) ──► 4. Проверка (код) ──► 5. Маршруты (2ГИС)
           категории,          радиус из бюджета,         выбирает 1–3      ссылки только на     реальное время
           потребности,        открыто ли сейчас,         места, пишет      кандидатов; факты    в пути и линия
           время, ориентир,    сезон, погода,             «почему» и        подставляет код      на карте
           компания, язык      рейтинг, атрибуты          «что делать»
                               → 12 кандидатов
```

1. **Разбор запроса.** LLM превращает свободный текст в структуру: категории (из 23), потребности
   («с ноутбуком», «с ребёнком», «доступная среда»), бюджет времени, способ передвижения, ориентир
   («возле Mega Silk Way» → точка из базы), нужен ли маршрут. Язык ответа определяется по алфавиту.
2. **Поиск (retrieval).** Без LLM, по базе POI: радиус считается из бюджета времени и скорости
   передвижения; отбрасываются закрытые места и те, что закроются раньше, чем вы успеете дойти и
   побыть там; сезонные объекты (фонтаны, открытые катки) — вне сезона. Ранжирование: расстояние,
   рейтинг с учётом числа отзывов, совпадение атрибутов 2ГИС с потребностями, ключевые слова в описании.
   Ограничение на одну категорию даёт разнообразную выдачу.
3. **Генерация.** LLM получает только кандидатов с готовыми фактами и выбирает 1–3 места (для маршрута —
   3 в порядке обхода), объясняет выбор и предлагает план. Может добавить «идею» — она помечается как
   идея ИИ, не данные.
4. **Проверка.** Ссылки модели на места сверяются с кандидатами по ref и названию — выдуманное место
   отбрасывается. Расстояние, время в пути, часы работы, рейтинг и ссылка на 2ГИС берутся из базы.
5. **Маршруты.** Для выбранных мест строятся реальные маршруты 2ГИС (параллельно, с кешем): пешком и на
   машине — Routing API, на транспорте — Public Transport API с номерами маршрутов. Для мини-маршрута —
   цепочкой: старт → 1 → 2 → 3.

**Погода** (Open-Meteo, прогноз на нужный час): в мороз, сильный ветер или дождь места на улице
понижаются в выдаче, радиус пешей прогулки сокращается, модель объясняет выбор погодой. Для демо в
интерфейсе есть пресеты «+24° ясно», «дождь», «−25° метель».

## Данные

- **Источник:** 2ГИС Places API (`catalog.api.2gis.com/3.0/items`). Сбор полностью автоматизирован:
  `python -m seruen.collect`.
- **Как собирается:** частые категории (кафе, кофейни, рестораны, бары, парки, достопримечательности,
  детское) — обходом города сеткой точек с шагом 2.5 км; редкие (музеи, театры, катки, квесты…) —
  одним запросом на город. Поиск 2ГИС нечёткий, поэтому категория определяется по рубрикам объекта,
  а не по запросу. Ответы кешируются: повторный запуск бесплатен и продолжает с места остановки.
- **Объём:** 1634 места в 23 категориях; у 1287 есть расписание, у 1513 — рейтинг, у 83 — описание.
- **Поля:** название, координаты, категории и рубрики, адрес, описание, атрибуты («Можно с ноутбуком»,
  «Детская комната», «Доступный вход для людей с инвалидностью»…), расписание, рейтинг и число отзывов,
  ссылка на 2ГИС.
- **Ограничение демо-ключа 2ГИС:** не больше 50 результатов на запрос (10 × 5 страниц), поэтому в
  самых плотных районах собраны лучшие по рейтингу места, а не все.

## Этика и приватность

- **Минимум данных о пользователе.** Точка округляется до ~100 м, нигде не сохраняется. В LLM уходит
  только название стартовой точки и расстояния до мест — не координаты.
- **Прозрачность.** В интерфейсе блок «Как система пришла к ответу»: распознанные категории и
  потребности, радиус поиска, фильтры, таблица всех кандидатов с оценками, модель-генератор.
- **Честность про данные.** Если у заведения нет расписания — «часы работы неизвестны, лучше уточнить»,
  а не «открыто». Объекты под открытым небом помечены отдельно. Идеи модели помечены «Идея ИИ — не из
  базы 2ГИС». У каждой рекомендации — ссылка на источник.
- **Против галлюцинаций.** Модель выбирает только из кандидатов; ссылки проверяются кодом; факты
  (расстояние, часы, рейтинг) подставляет код.
- **Аккаунты.** Пароли хранит Supabase Auth (только хеш). Сервер проверяет токен пользователя на каждом
  запросе: публиковать, лайкать и жаловаться можно только от своего имени. Регистрации ограничены
  5 в час с одного адреса.
- **Лента.** Доступ к базе только с сервера (ключ не попадает в браузер, RLS закрывает таблицы от
  публичного ключа). Место поста берётся из каталога по id — подделать название или координаты нельзя.
  В посте нет местоположения автора, только место. Тексты отзывов не попадают в промпт рекомендаций —
  только число отзывов и лайков, чтобы через отзыв нельзя было подменить инструкции модели.
  Модерация: регулярные выражения (телефоны, почта, ссылки) + модель безопасности; лимит 5 постов
  за 10 минут; жалобы.

## Ограничения

- Отбор кандидатов идёт по расстоянию по прямой (×1.3 на извилистость); реальный маршрут 2ГИС строится
  только для выбранных мест. Если 2ГИС не ответил, показывается оценка — она помечена.
- Время на общественном транспорте 2ГИС считает на текущий момент, а не на время, заданное вручную.
- Некоторые места в 2ГИС записаны дважды (например, Байтерек как достопримечательность без расписания и
  как организация с часами работы) — модель может взять запись без расписания.
- Временных событий (выставки, концерты) в базе нет: 2ГИС их не отдаёт.
- Бесплатный тариф Groq — около 8000 токенов в минуту на модель; при упоре в лимит ответ генерирует
  запасная модель `gpt-oss-20b`.
- Описания есть только у 83 мест, в основном у достопримечательностей.
- Распознавание по фото: у модели с картинками на бесплатном Groq маленький лимит в минуту — первое фото
  распознаётся за 1–10 с, несколько подряд могут ждать до 30 с. Узнаёт заметные здания и памятники
  в радиусе 2,5 км от выбранной точки.
- Аккаунты создаются сразу подтверждёнными, без письма на почту: бесплатный Supabase отправляет лишь
  несколько писем в час. Для продакшена — включить подтверждение email.
- Для показа лента наполнена демо-данными (`python -m seruen.demo_seed`): 3 аккаунта с плашкой «демо»
  и 10 подсказок, составленных только по данным 2ГИС (описания, атрибуты, часы работы), — это не
  личные отзывы. Их лайки участвуют в сигнале «советуют в ленте». Перед реальным запуском —
  `python -m seruen.demo_seed --remove`.

```
server.py               веб-сервер (FastAPI): API + фронтенд
web/                    фронтенд: index.html, style.css, app.js (Leaflet + карта 2ГИС),
                        city3d.js (3D-пролёт), pulse3d.js («Пульс города»), ground3d.js (карта 2ГИС в 3D)
                        — three.js, грузятся по кнопке
app.py                  первое демо на Streamlit (запасной вариант)
seruen/
  quest.py              квест-прогулка: выбор точек, задания и вопросы по описаниям 2ГИС
  social.py             лента: Supabase, модерация, лайки, жалобы, сигнал для рекомендаций
  auth.py               регистрация, вход, обновление сессии, проверка токена (Supabase Auth)
  vision.py             «Что это за место?» — распознавание по фото среди мест рядом
  pulse.py              данные для «Пульса города»: все места с расписанием в компактном виде
  business.py           Seruen для бизнеса: заявки, предложения, статистика, ключи API
  admin.py              панель администратора: сводка, модерация, пользователи, состояние системы
  make_admin.py         создать администратора или выдать/снять роль
db/003_business.sql     заведения, предложения и их статистика
db/schema.sql           таблицы ленты для Supabase
db/002_auth.sql         привязка профилей к аккаунтам и паспорт в профиле
  collect.py            автоматический сбор POI из 2ГИС
  dgis.py               клиент 2ГИС с кешем и повторами
  categories.py         таксономия мест и правила по рубрикам
  poi.py                нормализация объектов, расписание, «открыто ли сейчас»
  recommend.py          RAG: разбор запроса, поиск, генерация, проверка, «другие варианты»
  routing.py            реальные маршруты 2ГИС (пешком, машина, транспорт) и ссылки в 2ГИС
  weather.py            погода Open-Meteo и её влияние на выдачу
  voice.py              голосовой ввод (Whisper) и озвучка (ElevenLabs)
  scenarios.py          тестовые сценарии
data/pois.json          собранная база мест
```
